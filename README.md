# 마왕성 퇴근 심사 · 그림자 분실 사건

브라우저에서 바로 플레이하는 1인용 방탈출 웹게임입니다.

- 플레이: https://maou-escape.github.io/demon-castle-escape/
- 예상 플레이 시간: 처음 플레이 기준 30~45분 (설계 목표)
- 진행은 브라우저에 자동 저장됩니다.

![미리보기](docs/preview.png)

## 파일 구성

| 경로 | 내용 |
| --- | --- |
| `index.html` | 화면 뼈대 |
| `game.js` | 게임 전체 스크립트 (섹션 00~09 순서로 실행) |
| `*.css` | 화면 디자인 |
| `assets/` | 방 배경 그림 (WebP) |
| `docs/` | 제작 기록·디자인 메모 (게임 실행에는 쓰이지 않음) |

## 로컬 실행

저장소를 내려받아 `index.html`을 브라우저로 열면 됩니다.
