# 게임 오디오

외부 음원이나 샘플을 다운로드하지 않고 `game-audio.js`에서 직접 합성합니다. 특정 기존 곡을 편곡한 것이 아니라, 이번 게임용 음표·코드 패턴을 작성했습니다.

- BGM: 78 BPM, 16마디(약 49초) 반복. 전자 피아노 계열 음색과 베이스.
- 효과음: 조작 클릭, 물건 획득, 성공·실패, 복도 회전, 천 마찰, 미믹 식사, 거울 울림, 관송기 운송, 엔딩 아르페지오.
- 시작 화면에서 소리 켜고 시작 또는 무음으로 시작을 선택합니다.
- 이미 진행 중인 경우 상단 소리 설정에서 소리를 켭니다.
- BGM·효과음 음량을 따로 저장합니다. 새로고침 후에는 다시 소리를 켜야 합니다.
- 업무 모드 진입 시 음소거합니다. 일반 보기로 돌아와도 직접 켜기 전에는 무음입니다.
- 다른 탭으로 이동하면 일시정지합니다.
- 별도 음원 파일이나 API 키가 필요 없습니다. 배포할 때 **game-audio.js**를 다른 스크립트와 함께 포함하세요.

현재는 합성 음색으로 구성한 첫 오디오 버전입니다. 실제 녹음 효과음이나 전문 음악 제작물과는 질감 차이가 있습니다. 기존 요청에 따라 브라우저 재생·청취 검증은 수행하지 않았습니다.
