# 그림자 분실 사건 — 확장판 안내

열려 있는 http://localhost:8766/ 를 새로고침하세요.
기존 소지품과 해결한 퍼즐은 이어집니다. 이전 판을 완료했다면 추가된 원본 회수와 새 마지막 퍼즐을 진행할 수 있습니다.

## 이번 변경

- 일지·문서·힌트에서 이전 문제 화면으로 돌아갑니다. 자료 고정 후에도 바로 돌아갈 수 있습니다.
- 각 장치 조사창에 해당 문제의 3단계 힌트를 제공합니다. 상단 힌트에서는 현재 방의 문제를 선택합니다.
- 거리와 크기를 추측하던 그림자 센서는 삭제하고, 세 필름의 검은 칸을 원본 도안에 맞추는 2D 퍼즐로 교체했습니다.
- 기록실의 빈 운송장과 새 문서 수발실을 추가했습니다. 숨은 글씨 발견 → 배전함 복구 → 우회 배송 → 원본 회수 → 필름 판독으로 이어집니다.
- 신규 배경 이미지 없이 장치와 자료 도식으로 구성했습니다.

## 조작

소지품을 누르면 조사·뒤집기·조합이 가능합니다. 장치 아래의 소지품 목록에서 사용할 물건을 고른 뒤 사용을 누르세요.
일지는 읽고 돌아가기, 힌트는 문제로 돌아가기를 누르면 됩니다. 문서를 고정하면 장치 옆에 함께 표시됩니다.
필름은 각자 90도씩 회전합니다. 원본과 겹친 결과에서 검은 칸의 위치를 비교하세요. 필름 안의 A/B/C는 그 칸을 덮는 필름 이름입니다.
F2 업무 모드, 자동 저장, 소리 없이 플레이할 수 있는 구성은 유지했습니다.

## 플레이 시간

첫 플레이 30~45분을 설계 목표로 삼았습니다. 공략 숙지 여부와 힌트 사용에 따라 차이가 큽니다. 실제 측정 결과가 아닙니다.
사용자 요청에 따라 브라우저 플레이와 자동 테스트는 수행하지 않았습니다.
