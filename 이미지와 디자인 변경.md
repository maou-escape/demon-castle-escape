## UI 구성

색상: ink #141924, vermilion #df3046, ivory #f5f3ed, teal #79d9d0.
타이포그래피: Noto Sans KR 중심의 굵은 제목과 명확한 본문.
배치: 방 제목·상태 → 비율 고정 배경 → 조사 대상 버튼 → 대사 → 장소 이동 → 소지품.
기록실과 수발실은 동일한 색상 체계의 조작 도식을 사용합니다. 사선은 배경의 넓은 면에 한정하고, 읽는 글자와 조작 버튼은 기울이지 않았습니다.

스크린샷에서 발견된 제목·상태 중첩과 그림 위 대사는 각각 독립된 문서 흐름 영역으로 옮겼습니다. 배경 위 핫스폿과 아래 대상 목록은 동일한 번호로 연결됩니다.

사용자의 이전 요청에 따라 브라우저 검증과 플레이 테스트는 수행하지 않았습니다.
